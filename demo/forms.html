dux-pjax

Form interception

Forms tagged with data-pjax submit through PJAX automatically — no onsubmit needed. Field values are appended to the action URL as query params.

Full-swap form

data-pjax="true" swaps the response into #pjax like a regular Pjax.load.

After submit, you'll land on the Query string page and see ?foo=… reflected there.

Targeted form

data-pjax="#form-out" swaps the response's matching node into #form-out. URL is not pushed.

#form-out token:

The full URL (with your form data) appears in the event log on the right.
