dux-pjax

Works well with Fez

dux-pjax pairs naturally with Fez, a tiny DOM components framework. When Fez is loaded, Pjax.morphInto automatically uses Fez.nodeMorph instead of innerHTML, so component instances and form input state are preserved across swaps.

Fez on GitHub  *  Fez demo pages

Why it matters

  • Stateful components inside #pjax are diffed, not replaced.
  • Form inputs with stable ids keep their typed value across same-page refreshes.
  • Components that live outside #pjax (header, menu, event log) survive every navigation.
  • Components can subscribe to pjax:render on document to react to swaps.
