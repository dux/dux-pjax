Inline scripts

Inline <script> tags in a response are replayed by Pjax.parseScripts. By default they run before the morph — tag with pjax-delay to defer to the next animation frame.

Demo

Click Refresh repeatedly. The pre-morph script runs every time (the counter goes up), but its DOM writes never make it on screen — the morph that follows replaces them. The pjax-delay script writes after the morph, so its timestamp updates as expected.

The pre-morph script's DOM write is discarded, but its global state (window.__preCount) persists. That's the use case — seed globals or wire listeners pre-morph; do DOM work in pjax-delay or in a pjax:render listener.

Why this exists

Pre-morph scripts are useful for seeding globals or registering listeners that the rendered markup will consume on pjax:render. For DOM wiring against the just-inserted nodes, prefer pjax-delay or a pjax:render listener.
