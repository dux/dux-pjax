Confirm hook

pjax-confirm on a link prompts before navigating. Override Pjax.confirm for a custom modal — return a Promise to hold the click while the user decides.

Custom modal (this demo)

The demo's boot script wires:

Pjax.confirm = (msg, node) => window.DemoConfirm.ask(msg, node)

Where <demo-confirm> is a fez singleton (see demo/components/demo-confirm.fez).

Confirm + Refresh Confirm + Lifecycle

API

Pjax.confirm = (message, node) => {
  const yes = node.getAttribute('pjax-yes') || 'Confirm'
  const no  = node.getAttribute('pjax-no')  || 'Cancel'
  return new Promise(resolve => {
    myModal.show({
      message, yes, no,
      onConfirm: () => resolve(true),
      onCancel:  () => resolve(false),
    })
  })
}

Returning a non-Promise boolean is also fine — the click resolves synchronously.

Default behavior

Without an override, Pjax.confirm calls window.confirm:

<a href="/users/42" pjax-confirm="Delete this user?">Delete</a>
