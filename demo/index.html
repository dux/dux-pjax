dux-pjax

PJAX navigation, ~5 KB

dux-pjax swaps a container's HTML instead of reloading the page. PushState + AJAX, scoped refreshes, lifecycle events, custom confirm hook, form interception, inline-script replay. 

import Pjax from 'dux-pjax'
Pjax.onDocumentClick()        // hijack eligible links once

Pjax.load('/users')           // navigate
Pjax.refresh('#sidebar')      // refresh in place
Pjax.reload()                 // hard reload, no cache

How this demo works

Each menu link is a separate .html file. Clicks are intercepted by Pjax.onDocumentClick(); only the contents of #pjax swap. The header, the menu, and the event log on the right live outside the swap target — they survive every navigation.

Watch the event log on the right as you click. Every pjax:* event shows up in real time.

fez components in this demo:

  • <demo-menu> — the top navigation
  • <demo-event-log> — the live event panel (outside #pjax)
  • <demo-confirm> — singleton modal wired into Pjax.confirm
  • <demo-counter> — stateful demo on the Preserve page
  • <demo-api> — the table below

When fez is loaded, Pjax.morphInto automatically uses Fez.nodeMorph instead of innerHTML, so component instances and form input state are preserved across swaps.
