dux-pjax

Lifecycle

One event, one hook: pjax:render fires once per navigation, and Pjax.before can cancel one before it starts.

The event

pjax:render is dispatched on document for every navigation — success or failure. event.detail carries everything you need:

{
  from:     '/old/path',  // previous path, null on initial load
  to:       '/new/path',  // navigation target
  status:   200,          // HTTP status, 0 for network/timeout
  error:    null,         // 'network' | 'timeout' | 'status' | 'apply' on failure
  duration: 145,          // ms, request start → render
  mode:     'full',       // 'full' | 'target' | 'ajax'
  opts:     { … },        // the original options bag
}

Trigger anything from the menu and watch the panel on the right.

Cancel a navigation

The cancellation hook is Pjax.before(href, opts). Return false to abort — no XHR, no pjax:render.

cancel armed: no

Listening

document.addEventListener('pjax:render', (e) => {
  const { status, error, to, mode, duration } = e.detail
  if (error) console.warn('navigation failed:', error, status, to)
  else       console.log('rendered', to, 'in', duration, 'ms')
})
